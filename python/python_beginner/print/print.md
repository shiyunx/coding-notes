## Print

### Basic print

```python
print(value)
```

### Print text

```python
print("text")
```

### Print number

```python
print(number)
```

### Print variables

```python
variable = value
print(variable)
```

### Print multiple values

```python
print(value1, value2)
```

### Print with calculations

```python
print(expression)
```

### Print f-string

```python
print(f"text {expression}")
```

### Print separtaor 

```python
print(value1, value2, sep="separator")
```

### Print end

```python
print(value, end="something")
```

### Print newline

```python
print("text\ntext")
```

### Print tab

```python
print("text\ttext")
```

### Print data type

```python
print(type(variable))
```
