## Data Types

### Declare variable

```python
variable_name = value
```

### String

```python
variable_text = "text"

print (variable_text)
```

### Integer

```python
variable_whole_number = 1

print (variable_whole_number)
```

### Float
```python
variable_decimal_number = 1.1

print (variable_decimal_number)
```

### boolean

```python
# True
variable = True

# False
variable = False
```

### List

```python
variable = [value1, value2, value3]
```

### Tuple

```python
variable = (value1, value2, value3)
```

### Dictionary

```python
variable = {
    "key": value
}
```

### Set

```python
variable = {value1, value2, value3}
```

### None

```python
variable = None
```
