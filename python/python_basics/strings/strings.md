## Strings

### Create a string

```python
variable = "text"
```

### String concatenation

```python
string1 + string2
```

### String repetition

```python
string * number
```

### String length

```python
len(string)
```

### String index

```python
string[index]
```

### String slice

```python
string[start:end]
```

### Change case

```python
# upper()
string.upper()
```

```python
# lower()
string.lower()
```

```python
text = "python"
print(text.title())
```

### Remove spaces

```python
string.strip()
```

### replace text

```python
string.replace(old, new)
```

### Find text

```python
string.find("text")
```

### Check whether text exists

```python
"text" in string
```

### String format: f-string

```python
f"text {variable}"
```

### Multiple variables: f-string

```python
f"text {variable1} text {variable2}"
```
