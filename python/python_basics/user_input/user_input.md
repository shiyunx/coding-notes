## User Input

### Basic input

```python
variable = input("Question: ")
```

### Convert input to integer

```python
variable = int(input("Question: "))
```

### Convert input to float

```python
variable = float(input("Question: "))
```

### String input

```python
variable = input("Question: ")
```

### Multiple user inputs

```python
variable1 = input("Question 1: ")
variable2 = input("Question 2: ")
```

### User input and calculation

```python
number1 = int(input("Enter number: "))
number2 = int(input("Enter number: "))

result = number1 + number2

print(result)
```

### User input and f-string

```python
name = input("Enter name: ")

print(f"Hello, {name}!")
```

### User input and if

```python
value = int(input("Question: "))

if value > condition:
    print("...")
else:
    print("...")
```

### User input and multiple conditions

```python
value = int(input("Question: "))

if condition:
    ...
elif condition:
    ...
else:
    ...
```

### User input and strip

```python
variable = input("Question: ").strip()
```

### User input and lower

```python
variable = input("Question: ").lower()
```

### User Input and validation

```python
variable = input("Enter value: ")

if condition:
    print("Valid")
else:
    print("Invalid")
```
