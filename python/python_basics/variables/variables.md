## Variables

### Create a variable

```python
variable_name = value
```

### Assign multiple variables

```python
variable1, variable2 = value1, value2
```

### Assign same values

```python
variable1 = variable2 = value
```

### Change a variable

```python
variable = new_value
```

### Variables and calculations

```python
result = variable1 operator variable2
```

### Variables and strings

```python
variable = "text"
```

### Variables and f-string

```python
f"text {variable}"
```

### Get user input

```python
variable = input("message")
```

### Input and numbers

```python
variable = int(input("message"))
```

### Check variable type

```python
type(variable)
```

### Convert variable types

```python
int(value)
float(value)
str(value)
bool(value)
```

### Variable comparision

```python
variable1 comparison_operator variable2
```

### Variable and boolean

```python
variable = True

variable = False
```

### Variable and if

```python
variable = value

if variable comparison_operator value:
    print("Result")
```
