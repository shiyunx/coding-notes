## Tuple

### Create a tuple

```python
tuple_name = (value1, value2, value3)
```

### Tuple with different data types

```python
tuple_name = (value1, value2, value3)
```

### Access tuple items

```python
tuple_name[index]
```

### Negative index

```python
tuple_name[-1]
```

### Tuple length

```python
len(tuple_name)
```

### One item tuple

```python
tuple_name = (value,)
```

### Assign tuple values to multiple variables

```python
variable1, variable2, variable3 = tuple_name
```

### Tuple slice

```python
tuple_name[start:stop]
```

### Check if item exists

```python
value in tuple_name
```

### Count items

```python
tuple_name.count(value)
```

### Find item position

```python
tuple_name.index(value)
```

### Tuple concatenation

```python
tuple1 + tuple2
```

### Repeat a tuple

```python
tuple_name * number
```
